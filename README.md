# CSTR simulation and PID control 
This is for leaching simulation plant design with DWSIM, and PID control for the temperature and reactant levels in the tank to be stabilised at steady state. The DWSIM simulation shows cobalt recovery from a side stream, which was then neutralised using sodium carbonate. The precipitate was then separated from the supernatant. The Python code simulates testing reactor temperature regulation. The reaction is at 60°C, and it takes about 50 minutes to heat up and stabilise (from the simulation result). This is also consistent with filling the tank to a volume of 60 m^3 (the CSTR tank size is 100 m^3). The level simulation was also put to test with a step up to 65 m^3 which adjusted in about an hour with some overshoots (Kc and Ki can be tuned to adjust this). A simulation using a non linear MPC, can also be considered in this case.  The link to the process design, and the PI control code are on the ipynb file.
